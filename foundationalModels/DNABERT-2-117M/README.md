This is the adaptaion of the official pre-trained model introduced in [DNABERT-2: Efficient Foundation Model and Benchmark For Multi-Species Genome
](https://arxiv.org/pdf/2306.15006.pdf).

While the original model and code are avaliable via huggingface "zhihan1996/DNABERT-2-117M", this copy implements several changes to be compatible with the latest libraries versions as well as with the overal methyldl project
